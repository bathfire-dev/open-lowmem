# open-lowmem: запуск LLM на 125 млрд параметров со скоростью ~75 токенов/с на видеокарте 24 ГБ и 32 ГБ ОЗУ (Windows)

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Русский](README.ru.md) | [Português](README.pt-BR.md)

**Огромные LLM на малом объёме памяти.** Запускатели для Windows в один клик: они локально запускают **MoE-модель на 125 миллиардов параметров (Qwen3.8-Flash-Next)** на обычном ПК с **видеокартой 24 ГБ и 32 ГБ ОЗУ** и подключают её к **Claude Code, OpenCode, десктопному приложению Claude и Open WebUI**. Офлайн, приватно, бесплатно.

Автор: **廖亦辰 (Liao Yichen)** · Сямэнь, Китай · GitHub [@bathfire-dev](https://github.com/bathfire-dev) · Лицензия: MIT

> Если проект сэкономил вам выходные на настройку, звезда поможет другим владельцам небольших GPU его найти.

## Что это?

`open-lowmem` — набор небольших лаунчеров на Go для Windows. Каждый сначала запускает локальный движок инференса [Strata](https://github.com/Niko1221/Strata). Он распределяет работу между видеопамятью GPU, оперативной памятью и SSD, и модель типа «смесь экспертов» на 125 млрд параметров помещается в обычный игровой ПК. Затем лаунчер запускает выбранный клиент и всё убирает за собой при закрытии окна.

Ключевые слова: локальная LLM, мало VRAM, малый объём памяти, большие языковые модели на GPU 24 ГБ, MoE, квантизация (IQ2_XS), Qwen3.8-Flash-Next, Strata, Claude Code с локальной моделью, OpenCode, офлайн-помощник по программированию на ИИ, RTX 4090, Windows.

## Измеренная скорость

Измерено на машине разработчика этого репозитория (RTX 4090D 24 ГБ, 32 ГБ ОЗУ, IQ2_XS, Windows, 7 октября 2026): 8 запусков по 512 сгенерированных токенов дали **от 62 до 94 токенов/с, медиана около 77**. Один запрос за раз, короткий промпт. Ваша скорость зависит от длины контекста, фоновой нагрузки и размера модели.

## Сколько нужно памяти?

Цифры взяты из [документации Strata](https://github.com/Niko1221/Strata), а не из измерений в этом репозитории:

| Размер (одна и та же модель) | Нужно ОЗУ + VRAM | Примечания |
| --- | --- | --- |
| Q2_0 | около 37,6 ГБ | самый быстрый |
| IQ2_XS | около 39,2 ГБ | рекомендуется; конфигурация по умолчанию в этом репозитории |
| IQ3_XXS / IQ3_S | около 47 / 55 ГБ | лучше качество, больше ОЗУ |

Strata требует видеокарту NVIDIA или AMD от 12 ГБ, от 32 ГБ ОЗУ и около 80 ГБ свободного места на диске. Авторы измерили 79 токенов/с на RTX 5070 (12 ГБ) с 64 ГБ ОЗУ для IQ2_XS. С картой на 24 ГБ и 32 ГБ ОЗУ Q2_0 и IQ2_XS работают в режиме экономии ОЗУ в Strata. Этот репозиторий разрабатывается на RTX 4090D 24 ГБ с 32 ГБ ОЗУ.

## Лаунчеры

| Лаунчер | Что делает |
| --- | --- |
| `claude-strata.exe` | Запускает Strata, затем установленный у вас Claude Code с `--settings`. Ваш `~/.claude` не затрагивается. |
| `claude-strata-ui.exe` | Выбор папки, затем Strata и веб-интерфейс `claude-code-webui`. |
| `claude-desktop-strata.exe` | Запускает Strata, записывает профиль стороннего шлюза для десктопного приложения Claude и запускает приложение. |
| `opencode-qwen.exe`, `opencode-qwen-web.exe` | OpenCode в терминале и в вебе с встроенной конфигурацией. |
| `opencode-qwen-strata-desktop.exe` | Запускает Strata, затем десктопное приложение OpenCode. |
| `openwebui-qwen.exe` | Ollama и Open WebUI. |

При закрытии окна лаунчера все дочерние процессы завершаются через Windows Job Object, так что модель не продолжает занимать вашу видеопамять.

## Вопросы и ответы

**Можно ли запустить модель на 125 млрд параметров на GPU с 24 ГБ?**
Да, если это модель «смесь экспертов» и движок, который раскладывает экспертов по VRAM, ОЗУ и SSD. Именно это делает Strata; этот репозиторий лишь подключает её к вашим инструментам. Для IQ2_XS рассчитывайте примерно на 39 ГБ суммарно ОЗУ и VRAM.

**Как использовать Claude Code с локальной моделью?**
Strata предоставляет Anthropic-совместимую точку доступа (`/v1/messages` на `127.0.0.1:8090`). `claude-strata.exe` запускает Strata и запускает Claude Code с наложением настроек, которое указывает на неё; в качестве псевдонима используется имя модели Claude, например `claude-sonnet-4-6`. Сам Claude Code в репозиторий не входит; установите его у Anthropic.

**Работает ли десктопное приложение Claude?**
Не проверено. Профиль записывается, но неизвестно, примет ли приложение обычный шлюз `http://127.0.0.1:8090` без HTTPS. Считайте `claude-desktop-strata.exe` экспериментальным.

**Качество такое же, как у облачных моделей?**
Нет. Квантизация с малым числом бит обменивает качество на память. В публичных рейтингах Qwen3.8-Flash-Next — сильная открытая модель, но не передовая закрытая, а часть оценок сообщена самим разработчиком.

**Работает ли это на Linux или macOS?**
Сейчас нет. Лаунчеры используют API Windows.

## Важные замечания

- Strata, OpenCode, Claude Code, десктопное приложение Claude и веса модели **не входят** в репозиторий. Установите их самостоятельно.
- Независимый личный проект, не связан с Anthropic, Alibaba Cloud (Qwen), Strata и OpenCode.

## Сборка из исходников

1. Установите Go 1.25+, Node.js и PowerShell 5.1+.
2. Поместите Strata в `strata\Strata-main` (или задайте `STRATA_DIR`) и сгенерируйте её `run-*.bat`.
3. Выполните `npm install` в `opencode\` (лаунчеры OpenCode) и в `claudeui\` (веб-интерфейс).
4. Запустите `.\build.ps1` или `.\build.ps1 -Only <имя>`, где имя — одно из: tui, web, desktop, openwebui, strata, claude, claudewrap, claudeui, claudedesktop. Результат попадает в `dist\`.
